- png_300dpi/: 2625 x 3375 px print PNGs (incl. bleed), 300 dpi.
- digital/: 1080 x 1350 px PNGs for email and social.
- assets/images/: NOP logo (SVG + 1200 px transparent PNG, color and white). Default for agent_logo.
- field_map.json: every variable zone for all 8 templates, print (in) and digital (px).
- brand.json, ASSETS.md, fonts/.

## How to inject variable content
- Text fields: each `[data-var]` element contains ONE styled `<span>` (font, size, weight, color, letter-spacing live on this span), which wraps an empty `<span class="sc-interp"></span>`. Insert the value into `span.sc-interp`. Do not move styles to the `data-var` element or replace the styled span.
  Example: `<div data-var="agent_name" data-fit-base="22" data-fit-min="16"><span style="font-size:22px;…"><span class="sc-interp">Maria Hernandez</span></span></div>`
- Shrink-to-fit is NOT done by the static HTML. Your rendering engine must apply it to elements with `data-fit-base` / `data-fit-min` (values in CSS px): set the styled span's font-size to data-fit-base, then step it down until the text width fits the `data-var` box, stopping at data-fit-min. Applies to agent_name (22 → 16 px = 12 pt), agent_email (14 → 10.67 px = 8 pt), agent_slug (13 → 10.67 px = 8 pt).
- Image fields (agent_logo, qr_code): place the image inside the `data-var` box. agent_logo uses contain-fit, right/middle aligned. qr_code fills its 1.375 in square.

## Field rules
- Single line, never reflow. agent_name shrinks to fit (min 12 pt), agent_email and agent_slug shrink to fit (min 8 pt). Prices, phone, agent_id are fixed size.
- agent_id: numeric, max 10 characters. agent_slug is populated with agent_id.
- Printed URL = enroll_domain + agent_slug. enroll_domain is system-controlled (default "[SUBDOMAIN].basicbenefits.com/"; production "neighbor.basicbenefits.com/"), right-aligned.
- agent_logo: contain-fit, right/middle aligned, never crop or stretch; default to assets/images/nop_logo.png when none uploaded.
- Prices: US format, period decimal ($22.50). Number only; "per month" / "al mes" is artwork.
- version_stamp default: "NOP-P3-EN v1.1 10/2026" (comparison: "NOP-ALL-EN v1.1 10/2026").
- Nothing may overlap qr_zone; it must stay white.
